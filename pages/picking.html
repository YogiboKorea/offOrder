통합 피킹리스트

진행중 매장 주문(상품/발주)을 품목별로 합친 목록
사용 방법 진행중인 매장 주문을 품목별로 합친 목록입니다. 창고에서 꺼낼 품목과 매장별로 나눠 담을 수량을 한 화면에서 봅니다.

10/19 바뀐 점 주문(상품/발주)와 주문(데모/발주)를 함께 합칩니다. 상품과 데모는 표 위 구분 버튼으로 나눠 보고, ‘전체’에서는 소제목으로 나뉩니다. 규격 옆에 물류센터 재고(매장을 고르면 매장 재고도)가 나옵니다. 꺼낸 품목은 체크할 수 있습니다.

작업 순서

  1. 최신 주문 가져오기위의 실시간 데이터 가져오기 → 확인창에서 가져오기. 1~2분 뒤 화면이 저절로 바뀝니다. 아래 데이터 기준 시각이 방금으로 바뀌었는지 확인하세요.
  2. 창고에서 꺼내기통합 피킹리스트 탭은 매장 구분 없는 품목별 총수량입니다. 꺼낸 품목은 왼쪽 칸을 체크하면 흐려지고 위에 진행률이 나옵니다. 남은 것만을 켜면 안 꺼낸 품목만 보입니다.
  3. 매장별로 나눠 담기매장별 분배 탭에서 매장마다 몇 개씩인지 봅니다. 표 위의 매장 버튼(또는 표의 매장 이름)을 누르면 그 매장 상자에 담을 품목만 나오고, 체크는 그 매장 담음으로 따로 셉니다.
  4. 주문서 확인포함된 주문 탭에서 합친 주문서(주문번호·매장·납기일)를 봅니다. 이미 출고한 주문이 섞여 있지 않은지 확인하세요.
  5. 엑셀 · 인쇄 (필요할 때)엑셀은 지금 고른 매장·구분 그대로 받습니다(예: 데모만 고르면 데모만). 둘 다 ‘전체’면 시트 3개 + 매장마다 시트입니다. 인쇄는 지금 보는 탭만 나갑니다.
  6. 출고 후 완료 처리출고가 끝난 주문서는 이카운트에서 완료로 바꿔 주세요. 진행중으로 남아 있으면 다음 목록에 또 합쳐집니다.

알아 두기

  • 새로고침하면 마지막으로 가져온 데이터를 그대로 보여 줍니다. 이카운트에서 새로 가져오는 건 실시간 데이터 가져오기를 눌렀을 때뿐이고, 10분에 한 번 가져올 수 있습니다.
  • 합치는 주문서: 이카운트 주문서조회에서 진행중이고 구분이 주문(상품/발주)·주문(데모/발주)인 것. 같은 품목이라도 상품과 데모는 줄을 나눕니다. 회수·데모 전환은 합치지 않고 포함된 주문 탭 아래에 따로 보여 줍니다. 완료된 주문서는 들어가지 않습니다.
  • 재고: 물류센터 재고는 상품 = 보유재고(물류센터), 데모 = 데모(물류센터)이고, 매장 재고는 그 매장의 상품(또는 데모) 창고입니다. 이카운트 창고별재고현황을 매일 저장한 값이라 위 재고 기준 시각을 확인하세요. 물류센터 재고가 전체 주문 수량보다 적으면 빨간색입니다.
  • 출고 수량 조정은 이카운트 주문서에서 고쳐 주세요(이 페이지는 이카운트를 읽기만 합니다). 고친 뒤 실시간 데이터 가져오기를 누르면 반영됩니다.
  • 체크는 통합 피킹리스트·매장별 분배 어디서 해도 같은 체크이고, 진행률은 어느 탭에서든 위에 보입니다. 이 페이지를 보는 모든 사람에게 같이 보입니다(다른 화면에는 15초 안에). 새로 가져와도 수량·주문서가 그대로인 품목은 체크가 남고, 바뀐 품목만 풀립니다.
  • 위의 숫자 카드(포함된 주문·매장·품목)를 누르면 그 목록으로 바로 갑니다.
  • 휴대폰으로 같은 주소를 열면 카드 모양으로 보이고, 내려도 진행률 막대가 위에 붙어 있습니다.
  • ‘물류 서버 PC가 꺼져 있거나…’ 안내가 나오면 서버 PC가 켜져 있는지 확인하거나 본사 담당자에게 알려 주세요.
